🗂️ Portal Arsip Terpadu Internal

Sistem manajemen dokumen dan arsip internal yang dibangun untuk memudahkan pencarian, pengarsipan, dan pratinjau surat resmi secara digital.

🌟 Fitur Utama

Kategorisasi Cerdas: Mendukung 7 jenis dokumen berbeda (Surat Tugas, Undangan, Berita Acara, Ranpermendagri, dll) dengan kolom isian yang menyesuaikan otomatis.

Dynamic Dropdown Wilayah: Otomatis memfilter pilihan Kabupaten/Kota berdasarkan Provinsi yang dipilih.

Live Preview: Pratinjau langsung dokumen dari Google Drive di dalam web tanpa harus mengunduh.

CMS Terintegrasi: Dikelola menggunakan antarmuka admin (Keystatic) yang ramah pengguna tanpa perlu paham coding.

🛠️ Teknologi yang Digunakan

Astro: Web framework (Mesin pembuat web statis super cepat).

Keystatic: Git-based CMS (Sistem formulir admin).

Tailwind CSS: Desain antarmuka (UI/UX) dan responsivitas.

GitHub & Vercel: Penyimpanan data dan Hosting web.
